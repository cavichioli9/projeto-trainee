# Projeto: Sistema de Ordem de Serviço

## Status do Projeto
* **Sprint Atual:** 0 (Configuração Inicial)
* **Objetivo:** Estabelecer a estrutura do repositório e as normas de commits.

## Normas da Equipe
1. Cada membro deve criar uma branch para sua tarefa.
2. Todo commit deve seguir o padrão: `tipo(escopo): descrição`.
3. Ao finalizar uma tarefa, anexar o PDF de relatório na pasta `/docs/sprints/`.

## Estrutura de Documentação
- `/docs/sprints/`: Relatórios individuais em PDF.
- `/src/`: Código fonte do sistema.
