# Visão do Projeto

## Nome do Projeto
Sistema de Ordem de Serviço

## Objetivo
Desenvolver um sistema web para gerenciamento de ordens de serviço.

## Público-Alvo
Empresas de suporte técnico, manutenção e prestadores de serviço.

## Problema Resolvido
Facilitar o controle de atendimentos e organização das ordens de serviço.

## Funcionalidades Principais
- Cadastro de clientes
- Cadastro de técnicos
- Criação de ordens de serviço
- Controle de status
- Histórico de serviços
- Relatórios
